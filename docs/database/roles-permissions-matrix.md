# مصفوفة الأدوار والصلاحيات

| الإجراء | زائر | طالب | مدرّس معيّن | super_admin |
|---|---|---|---|---|
| قراءة بيانات كورس منشور (عنوان/وصف) | نعم | نعم | نعم | نعم |
| قراءة مسودات/أرشيف الكورسات | لا | لا | كورساته المعيّنة | نعم |
| إنشاء مسودة كورس | لا | لا | فقط إذا `can_create_course_drafts` | نعم |
| نشر/أرشفة كورس | لا | لا | لا | نعم |
| تعيين مدرّس لكورس | لا | لا | لا | نعم |
| تعديل دروس كورس | لا | لا | مع `can_edit_content` | نعم |
| إدارة امتحانات (مستقبلاً) | لا | لا | مع `can_manage_exams` | نعم |
| رؤية تقدم طلاب محدود | لا | لا | مع `can_view_student_progress` | نعم |
| إدارة الأسعار والمنتجات | لا | لا | لا | نعم |
| إنشاء طلب دفع | لا | لنفسه فقط | لا | نعم (إداريًا) |
| الموافقة/الرفض على الدفع | لا | لا | لا | نعم |
| إنشاء تسجيل `enrollment` مباشرة | لا | لا | لا | عبر دوال آمنة فقط |
| تحديث تقدمه في الدروس | لا | نعم (مع وصول ساري) | لا | نعم |
| قراءة/تعديل سجل التدقيق | لا | لا | لا | قراءة فقط / الكتابة عبر دوال |
| تغيير أدوار المستخدمين | لا | لا | لا | نعم (عدا ترقية super_admin) |
| تزويد حساب المالك | لا | لا | لا | عبر `service_role` فقط |

## ملاحظات إلزامية

- المدرّس **لا يمنح نفسه** صلاحيات ولا يوافق على مدفوعات ولا يغيّر الأسعار.
- الوصول للمحتوى المدفوع يعتمد على `enrollments` النشطة وغير المنتهية وغير المعلّقة.
- صلاحيات المدرّس تُقرأ من `course_staff_assignments` وليس من `courses.created_by` وحده.
