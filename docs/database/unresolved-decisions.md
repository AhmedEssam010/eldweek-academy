# قرارات معلّقة ومخاطر أمنية متبقية

## قرارات معلّقة

1. **مدة صلاحية الاشتراك الافتراضية**  
   هل التسجيل بلا انتهاء (`expires_at = NULL`) أم مدة ثابتة (شهر/ترم/سنة)؟

2. **تجديد الشراء لنفس المنتج**  
   التصميم الحالي يمدّد التسجيل النشط. هل يُفضَّل إغلاق القديم وإنشاء صف جديد مؤرشف؟

3. **التحقق من ملكية رقم الهاتف**  
   مزوّد OTP (Supabase Phone Auth / مزوّد مصري)، حدود المحاولات، والتحقق قبل ربط `phone_number` نهائيًا.

4. **هل يمكن للطالب رؤية `receipt_path` بعد الإرسال؟**  
   حاليًا نعم ضمن صفّه. قد نقيّد لاحقًا ونتركه للمالك فقط.

5. **عرض أسعار المنتجات للزوار**  
   مسموح للمنتجات النشطة المرتبطة بكورس منشور. هل السعر جزء من البيانات العامة أم بعد تسجيل الدخول فقط؟

6. **جداول الامتحانات**  
   الصلاحية `can_manage_exams` موجودة في التعيين، لكن جداول الامتحانات غير منشأة بعد.

7. **سياسة حذف الحسابات (GDPR/خصوصية)**  
   مسار حذف/إخفاء بيانات الطالب والإيصالات لم يُحسم.

8. **عمود `can_create_course_drafts`**  
   إضافة ضرورية لفرض قاعدة العمل، لكنها توسعة على قائمة الحقول الأصلية — بانتظار اعتماد صريح.

## مخاطر متبقية

| المخاطر | المستوى | التخفيف الحالي | المتبقي |
|---|---|---|---|
| تسريب `service_role` | عالٍ | غير مستخدم في الواجهة | انضباط تشغيلي + أسرار بيئة |
| تطبيق هجرة خاطئة على الإنتاج | عالٍ | ملفات محلية فقط الآن | staging + dry-run |
| استخدام OTP بشكل مسيء | متوسط | غير منفّذ بعد | rate limit + تحقق جهاز |
| تلاعب بمسار الإيصال قبل وجود Storage policies | متوسط | التخطيط فقط | bucket خاص + signed URLs |
| اعتماد الواجهة وحدها للتخويل | عالٍ إن حدث | RLS + triggers + RPCs | الالتزام باستدعائها من الخادم |
| قراءة metadata كورسات عبر سياسات متعددة | منخفض | فصل published/draft | اختبارات تكامل RLS |
| تزامن موافقات الدفع | متوسط | `FOR UPDATE` + فهارس فريدة | اختبار ضغط لاحقًا |
| عدم تنفيذ security suite فعليًا بعد | عالٍ تشغيليًا | suite جاهز محليًا | تشغيل على Docker/local DB |
| اعتماد أسماء أدوار DEFINER (`postgres`) | متوسط | OWNER TO postgres في الهجرة | التحقق بعد التطبيق الفعلي |

## ما بقي متعمّدًا غير منفّذ

- تطبيق الهجرات على Supabase البعيد
- واجهات المصادقة
- إنشاء حسابات حقيقية
- Storage buckets
- تعديل الصفحة الرئيسية
